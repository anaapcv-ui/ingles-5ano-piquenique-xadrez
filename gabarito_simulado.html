📗 Questão por questão

A alternativa certa aparece em verde. As outras aparecem em cinza, com a explicação do erro.

Questão 1. Complete: "_____ some yogurt."

✖️ a) Theres isn't
Não se junta There's com isn't, e com some a frase é afirmativa.
✔️ b) There's
Yogurt é singular e a frase diz que tem: There's some yogurt (p. 80).
✖️ c) There aren't
Aren't é negativo e para o plural.
✖️ d) There are
There are é para o plural.

Questão 2. Complete: "_____ some nuts."

✖️ a) There arent
Falta o apóstrofo e, com some, a frase é afirmativa.
✖️ b) There isn't
Isn't é negativo e para o singular.
✖️ c) There's
Nuts termina em s, é plural: There are.
✔️ d) There are
Nuts é plural: There are some nuts (p. 80).

Questão 3. Complete: "_____ any shish kebabs."

✖️ a) There isn't
Shish kebabs é plural: aren't.
✖️ b) There are
Com any, a frase é negativa.
✔️ c) There aren't
Plural + any (não tem) = There aren't any shish kebabs.
✖️ d) There's
Com any, a frase é negativa, e kebabs é plural.
